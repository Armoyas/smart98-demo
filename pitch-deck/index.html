The Problem

Vibe coders guess. Smart98 learns.

Without Smart98

  • Agent tries something
  • It fails
  • Agent tries again
  • It fails differently
  • No memory of failure
  • Same mistake next time
  • User manually patches

With Smart98

  • Agent tries something
  • It fails
  • Engine observes the pattern
  • Mines a recovery rule
  • Next attempt uses the rule
  • Success — with evidence
  • Rule approved → deployed
The key insight: In most tools, four failures is where the story ends. Smart98 treats failures as training data. The engine learns from practice — deterministically, with zero model calls.

MCP — Tool Discovery & Chat Invocation

Extend the platform without writing a single line of integration code.

How it works

  • MCP marketplace lists tools (name, description, version)
  • User opens tool picker in chat
  • Filters by name, discovers relevant tools
  • Invokes tool with typed arguments
  • Results rendered inline in chat
FR-001 Marketplace lists tools
FR-002 Chat invokes tools inline

Get Started

cd smart98-demo/goal-evolve
npm run demo        # 10 practice runs + evolution report
npm test             # prove the engine's guarantees
